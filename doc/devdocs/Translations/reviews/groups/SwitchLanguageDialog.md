# Key group SwitchLanguageDialog

Nov 16, 2026. The dialog that the menu Program Language opens in the Avalonia application: its title "Switch
Language" and the label "Select a language:" above the list of languages. Only French had them. claude-opus-5-5 at
effort max made every line below, and each entry says so in its comment.

- **Translated**: 48 lines, in 24 languages. Both follow the terms Switch Language and Select a language.
- **Not needed**: 2 lines. en-GB writes both keys as the English does.
- **Corrected**: none.
- **Left empty**: none.

Doubts: none. The title is the same text as the button Switch Language... of the group Shared, without the ellipsis.
